Over deze versie

The DOS game Yogho Yogho (1995, Euphoria), running on an engine rewritten from scratch in C and compiled to WebAssembly — reverse-engineered from the original and checked frame by frame against it. Unofficial fan preservation project, not affiliated with the original makers or brand owners. Source.
